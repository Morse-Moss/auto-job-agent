# 使用者操作手册（受控触达 v1）

面向使用者本人。系统边界：AI 只准备内容、做记录、给提醒；所有真实发送和后续沟通由你亲自操作，系统不代发。

## 一、启动

推荐用一键启动脚本（它会先看端口所有者，再决定动作）：

```
py scripts/start_workbench.py
```

常用变体：

- `py scripts/start_workbench.py --check`：只检查，不启动任何服务
- `py scripts/start_workbench.py --no-browser`：不自动启动 MorseTools 浏览器服务
- `py scripts/start_workbench.py --review-port 8780`：换一个审核服务端口

脚本行为（重要）：

- 健康实例直接复用，不重启、不杀进程；端口被别的程序占用时只报告并给处理建议。
- 缺失的服务以脱离当前终端的方式后台启动，关掉终端不会带走服务。
- 明确区分"浏览器能打开"和"发送可用的 CDP 端点"：脚本会真正请求协定的 CDP 端点
  （默认 127.0.0.1:17332）的 `/json/version`，普通 Edge 可用不等于该端点可用。
- 打印当前运行版本与加载时刻；若检测到"代码已更新但服务未重启"，会明确提示需要重启。
- 打开页面、执行该脚本都不会采集数据、不会调用模型、不会发送消息。

手动启动（与脚本等价）：

1. 启动浏览器服务（发送前置条件）：
   在 `E:\MorseTools\browser-service` 运行 `npm run dev -- --profile general-web`，
   使用已登录 Boss 直聘的浏览器配置（127.0.0.1:17332）。
   登录态失效时，先在这个浏览器里手动重新登录 Boss。
2. 启动审核服务：
   `py main.py --review-jobs --review-port 8765`
   打开 http://127.0.0.1:8765 ，进入"投递准备"。

页面内一键启动（不用开命令行）：

- 位置：投递准备 → 受控发送 → 预检行。当预检显示"浏览器服务不可达"时，
  右侧会出现"一键启动浏览器服务"按钮。
- 点击后系统会调用 `POST /api/browser/start`，后台拉起 MorseTools general-web 并
  等待 CDP 就绪，然后自动重跑预检。
- 边界：这个按钮只解决"服务没起来"，不会代替你登录 Boss，也不会发送任何消息；
  登录态仍需你本人到 17332 那个浏览器里完成。只有"服务不可达"才显示该按钮，
  登录态异常时不会显示（避免误以为点一下就能自动登录）。
- 打开页面本身不会启动任何服务、不会采集、不会调模型、不会发送。

## 二、逐岗确认与发送（每岗流程）

1. 左侧岗位列表选一个岗位，检查 JD、匹配分析、招呼语、简历长图。
2. 选择成品简历：系统按 JD 关键词自动推荐三份之一（FDE / Agent / 产品），
   可手动切换；切换后长图确认会失效，需重新确认。
3. 确认招呼语（确认招呼语按钮）→ 确认长图（确认长图简历按钮）。两者都确认后
   发送门才可用；修改任一内容，对应确认自动失效。
4. 看发送门内的预检行：绿色=浏览器在线且登录态正常；红色=按提示先处理
   （启动浏览器服务或重新登录）。
5. 授权本岗 → 确认发送。授权只冻结当前版本快照；真实发送发生在你点击
   确认发送那一刻，一次只发一个岗位。
6. 发送后在下方"沟通进展"登记（已发送招呼语 / 对方已回复 / 约面试 / Offer /
   不合适）。AI 推断的记录带"待确认"标记，由你确认或忽略；你人工登记的
   记录永远不会被 AI 推断覆盖。

## 三、内容更新（JD 刷新）

- 界面：审核界面"更新岗位"区，或命令行 `py -m jobagent.jd_update --db output/jobagent.db`。
- 运行中可停止；刷新页面不丢进度；重复启动会复用同一任务。

## 四、故障排查

| 现象 | 处理 |
|---|---|
| 预检红色：浏览器服务不可达 | 点预检行右侧"一键启动浏览器服务"，或跑 `py scripts/start_workbench.py` |
| 预检红色：未检测到登录态 | 在 17332 浏览器里手动登录 Boss，再刷新页面（系统不代登录） |
| 长图显示破图/下载异常 | 已修复为 RFC 5987 编码；仍异常时重启审核服务 |
| 发送中触发 Boss 安全校验 | 系统立即暂停且不自动恢复，去浏览器人工处理后重试 |
| 测试 | `py -m pytest -q`；lint+构建+测试一键 `py scripts/ci.py` |

## 五、边界与红线

- 系统永远不自动发送消息、不自动回复、不代交换联系方式。
- 登录、验证码、安全警告出现时立即停，不刷新不试探。
- 秘钥、CDP 会话、真实简历母版内容、个人数据库不入远程仓库。
- AI 推断的沟通结果仅供参考，必须经你确认才采信。
