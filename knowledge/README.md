# 个人知识库

把能证明你实力的"弹药"放进这个目录（.md / .txt 格式），AI 生成打招呼语和定制简历时会引用这些内容：

- 项目深度复盘：背景 / 难点 / 技术方案 / 量化成果
- 技术亮点与数字：QPS、成本节省、性能提升百分比等
- 自我介绍话术、优势总结
- 博客文章、开源项目介绍

## 说明

- 除本 README 外，目录内容已被 .gitignore 忽略，**不会提交到仓库**，放心写真实信息
- 内容越具体、数字越多，AI 生成的招呼语和简历越有说服力
- 按文件名排序加载，超过 config.yaml 中 `knowledge.max_chars` 的部分会被截断，**重要内容命名靠前**（如 `01-核心项目.md`）
- AI 被明确约束：只能引用简历和知识库中真实存在的经历，不会编造
